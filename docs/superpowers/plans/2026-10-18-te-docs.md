# te-docs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create `wiz-training/te-docs`, the Tech Experiences team hub, with its layout, gates, agents, `/doc` skill and first seeded pages.

**Architecture:** A private repo checked out at `~/Work/te-docs` beside the other te repos. Two stdlib scripts are the gates: `lab-index.py` renders `labs/reference/index.md` from sibling lab repos, `doc-drift.py` resolves every mechanical reference a page makes. Three typed agents and one skill turn an `inbox/` folder into filed pages behind two human gates.

**Tech Stack:** Python 3.12 stdlib, `unittest`, Markdown, Claude Code agents and skills, GitHub (private, Free plan, no Actions).

**Spec:** `docs/superpowers/specs/2026-10-18-te-docs-design.md`

## Global Constraints

- Python stdlib only; every script answers `--self-test`; tests run with `python3 -m unittest discover -s tests`; `ruff check .` clean at ruff 0.16.9.
- Exit codes: 0 pass · 1 a rule fails · 2 usage or unreadable input · 3 `--self-test` fails or a sibling tool is unreadable.
- `CLAUDE.md` under 30 lines; `AGENTS.md` is a symlink to it. No page describes the folder tree except the root `README.md`.
- Every page except a `README.md` and a generated page opens with YAML front matter holding one key: `type: how-to | runbook | reference | explanation`.
- A generated page's first line is `<!-- generated by scripts/<name>.py on YYYY-MM-DD; do not edit -->`.
- `main` takes PRs only; `scripts/hooks/no-push-main.py` and the `.claude/settings.json` hook block are copied from te-labkit-v2 unchanged.
- A system folder is one of `team infra instruqt labs sandboxes okta gamekit events`; a subfolder `how-to/ reference/ explanation/` exists only when it holds a page.
- Scripts never call Instruqt or a tenant; they read sibling checkouts and git only.

## Review Focus

1. A lab repo whose `track-spec.json` is malformed JSON: the index still renders, the row carries flag `spec:unreadable`, exit 0. (Task 2)
2. `lab-index.py --check` run on a later day: the header date differs, the body is equal, exit 0. (Task 2)
3. A page names `te-foo/bar.md` and `../te-foo` is not cloned: the checker reports `skip: no checkout` and does not fail; a cloned repo missing the file fails. (Task 3)
4. A link anchor to a heading with backticks or punctuation, such as `#the-learner-shell` for `## The learner shell`: GitHub slug rules, lowercase, drop everything but letters, digits, spaces and hyphens, spaces to hyphens. (Task 3)
5. A placeholder such as `WIZ_<T>_LOGIN_URL` is not a secret reference; a real `WIZ_TBCMP_CLIENT_ID` absent from the inventory fails. (Task 3)
